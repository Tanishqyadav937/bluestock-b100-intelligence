# B100 Intelligence - Fundamental Analysis for Nifty 100

## Project Summary
Production-grade data engineering pipeline for Nifty 100 stock analysis.

## GitHub Repository
https://github.com/Tanishqyadav937/bluestock-b100-intelligence

## What was built
- ETL Pipeline: 3 Python scripts extracting, cleaning, loading 7 Excel files
- PostgreSQL Data Warehouse: 7 tables, 4,000+ rows
- ML Health Scoring: 100 companies scored (Excellent/Good/Average/Weak/Poor)
- EDA Jupyter Notebook: exploratory analysis with charts
- Power BI Excel Export: ready for dashboard building

## Tech Stack
Python, PostgreSQL, pandas, psycopg2, scikit-learn, Jupyter, Git

## Health Score Results
- Excellent: 21 companies (INFY, NESTLEIND, ASIANPAINT, BAJAJ-AUTO, COALINDIA)
- Good: 29 companies
- Average: 43 companies
- Weak: 5 companies
- Poor: 2 companies
